# 洞见思途 · 个人主页 V2（待发布）

单文件个人主页：`index.html` 一个文件即全部网站，无构建步骤，无外部脚本依赖（仅 Google Fonts 一个 CDN，加载失败时自动回退系统字体，不影响功能）。

## 内容结构

一个页面连续滚动，顺序为：

1. **洞见思途**（首屏）— WebGL 多色流体油墨，鼠标/手指搅动墨色，五色可选（胭脂红、群青、松石绿、金、紫）或混色模式，可「洗笔」清空；标题下有一句个人定位。
2. **三个观察方向**（概览）— 三个研究方向的入口：科学理解世界、人文理解人类、国际关系观察现实。
3. **科普杂谈** — 主题轮盘改成的研究兴趣探索组件（宇宙与物理 / 科学方法 / 技术与未来），无文章。
4. **忧郁的人类** — FBM 流体墨纹背景；五个思想主题可点击展开各自的关切说明，无文章。
5. **国际问题看法** — 可拖动的粒子地球，点阵由真实大陆轮廓构成（Natural Earth 地理数据采样，1512 个陆地点），无文章。
6. **关于我** — 地形线背景（随鼠标起伏）、个人自述原文、手写签名、邮箱。
7. **页脚** — 品牌、版权、身份署名行、邮箱、返回顶部。

全站支持简体中文 / 繁体中文 / 英文切换（localStorage 记忆）与深浅色主题（沿用原站 `theme-preference` 存储键）。JavaScript 不可用时正文默认可见。

## 部署到 GitHub Pages（linqinyu.loc.cc）

当前线上是占位页。发布本版本只需替换仓库中的 `index.html`，**`CNAME` 文件必须保留**（内容为 `linqinyu.loc.cc`，删掉它自定义域名会失效）。

方式一（网页操作）：打开 GitHub 仓库 `EnceladusLin.github.io` → 点 `index.html` → 右上角铅笔图标 → 全选粘贴新文件内容 → Commit changes。约 1 分钟后刷新 https://linqinyu.loc.cc 生效。

方式二：把本地的 `index.html` 发给 Muse，由 Muse 通过已授权的 GitHub 连接推送（推送前会再向你确认）。

回滚：仓库页面 → Commits → 找到上一个版本 → 恢复该版本的 `index.html` 再提交即可。
